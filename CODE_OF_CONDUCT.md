# Code of Conduct

We want IGuard to be a welcoming, harassment-free project for everyone.

**Expected:** be respectful and constructive; assume good faith; give and accept feedback graciously; focus on what
is best for the project and its users.

**Not acceptable:** harassment, discrimination, personal attacks, trolling, publishing others' private information,
or other conduct that would be inappropriate in a professional setting.

Maintainers may edit, remove or reject contributions and comments that violate this code, and may restrict
participation. Report concerns to the maintainer, Matin Alijani, at Matin.alijani@gmail.com; reports are treated
confidentially. This code applies in project spaces and when representing the project publicly.
