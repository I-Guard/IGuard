# Screenshots

No screenshots are included: none have been captured from a running, populated stack yet, and placeholders must not
be passed off as real output. To add them, run the stack (or `make dev`), capture the pages below at 1440x900, and
save them here as PNG with these names:

`overview.png`, `infrastructure.png`, `server-details.png`, `services.png`, `incident-details.png`,
`recovery.png`, `logs.png`, `alerts.png`, `reports.png`.

Do not include real hostnames, tokens or personal data.
