## Known gaps and risks

- Nothing has been run inside containers: Dockerfiles, nginx config, the compose network topology, the socket
  proxies, Promtail's Docker discovery and the agent's real restarts are untested. Expect first-run fixes.
- Frontend coverage was not measured. Integration tests for Prometheus/Loki use mocked HTTP transports, not real servers.
- Moderate npm advisories remain (react-router open-redirect class and similar); the app only navigates to
  internally generated paths. Re-run `npm audit` before release.
- The frontend pins zod 4 with `@hookform/resolvers` 5 and vitest 4; `.npmrc` sets `legacy-peer-deps` because npm's
  resolver fails on the vitest 4 peer graph in this environment.
- Playwright was run with a pre-installed Chromium via `E2E_CHROMIUM_PATH`; CI installs its own.
